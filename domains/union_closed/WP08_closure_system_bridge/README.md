# WP08: Closure-System Bridge for UC-P04

Date: 2026-09-24

## Purpose

WP07-D005 is a protected, independently qualified restricted theorem. The live
campaign obligation `UC-P04` asks how restricted and finite results could
connect to the universal half-frequency target.

The first proposed route was exact representation:

```text
arbitrary finite union-closed family
  -> complement of an exact D003 functional-preorder ideal family.
```

WP08 tests that route directly.

## Result of the first test

The exact representation route is false.

Every exact D003 functional-preorder ideal family is closed under both union and
intersection. Carrier-relative complementation swaps those two operations.
Therefore every family satisfying
`IsComplementOfFunctionalPreorderIdealFamily` is closed under both literal set
union and literal set intersection.

A concrete three-point family is

```text
G = { ∅, {a,b}, {b,c}, {a,b,c} }.
```

It is union-closed, nontrivial, contains both endpoint sets, and already
satisfies Frankl abundance. But

```text
{a,b} ∩ {b,c} = {b} ∉ G.
```

Hence it cannot be an exact D003 complement family.

The Lean endpoint is:

```lean
p04_no_universal_exact_functionalPreorder_representation
```

This closes one UC-P04 subroute negatively. It does **not** close UC-P04.

## Universal structure that survives

For a family carried by an explicit finite carrier `U`, complementation gives
an exact operation-level duality:

```text
G union-closed
  <-> complementFamilyOn G U intersection-closed.
```

If `∅ ∈ G`, the complement family also contains `U`; it is therefore a
finite closure system.

This reframes the universal problem:

```text
arbitrary union-closed family
  -> arbitrary finite closure system under complement

D003 / WP07
  -> a much narrower closure system that is ALSO union-closed
     and is generated by a functional preorder.
```

So the live mathematical gap is not “find the missing exact representation.”
The exact representation does not exist in general.

The gap is:

> Extend the rare-element argument from the functional-preorder closure systems
> handled by WP07 to broader finite closure systems, while preserving the
> incidence/frequency information needed by Frankl.

## Relation to WP05

WP05 works with the abstract finite-lattice formulation and derives strong
necessary conditions for a minimum counterexample. Those conditions do not by
themselves imply literal set-intersection closure of a concrete union-closed
family.

The three-point obstruction above makes the distinction visible. Its inclusion
poset is an abstract four-element diamond, even though the concrete family is
not closed under literal set intersection. Abstract lattice shape therefore
does not recover the ground-element incidence data used by the Frankl frequency
count.

The WP05/WP08 interface must consequently retain both:

1. lattice-order structure; and
2. the incidence map recording which ground elements occur in which family
   members.

An abstract lattice isomorphism alone is not a sufficient bridge to D005.
