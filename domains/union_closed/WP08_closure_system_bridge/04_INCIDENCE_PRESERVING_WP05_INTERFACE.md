# WP08-D004 — Incidence-Preserving WP05 Interface

## Protected planning object

D004 does not begin by translating the entire WP05 theorem catalogue. It first
builds one exact concrete incidence bridge.

The proposed principal carrier is every nonbottom lattice element. The proposed
principal trace of a is every retained x with x <= a. This choice is designed
so the coordinate frequency of x is exactly the lattice upper-cone count of x,
while bottom, which would be a dead complement coordinate, is omitted.

The reduced representation uses join-irreducible coordinates and asks whether
every lattice element is recovered exactly from the join-irreducibles below it.
D003's implication language can then be tested against finite joins directly.

## Work-package decomposition

equalities.

WP02 independently proves or falsifies the reduced join-irreducible
representation without distributivity assumptions.

WP03 independently reconstructs the closure/implication semantics and tests
whether valid implications are exactly finite join dependencies.

WP04 treats selected protected WP05 statements as conditional inputs and
performs only exact arithmetic/frequency translation.

WP05 attacks the representation on small nondistributive and endpoint examples.
