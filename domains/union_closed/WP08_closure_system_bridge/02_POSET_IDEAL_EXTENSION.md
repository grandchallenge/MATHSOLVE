# WP08-D002: Arbitrary Finite Poset Ideal Extension

Date: 2026-09-24

## Question

WP07 proved the half-frequency conclusion for complements of order-ideal
families generated by a **functional preorder**.  Is the functional self-map
restriction essential to the Frankl-facing conclusion?

## Result

No.

For every nonempty finite carrier inside an arbitrary partial order, the family
of all downward order ideals has a rare element.

Choose a maximal carrier element `m`.  Every ideal containing `m` can be
mapped to the ideal obtained by deleting `m`:

```text
I  |->  I \ {m}.
```

Maximality guarantees that the result is still an order ideal.  The map is
injective on ideals containing `m`, and its image consists of ideals omitting
`m`.  Hence the ideals containing `m` can be paired injectively with
distinct ideals not containing `m`:

```text
# ideals containing m <= # ideals omitting m.
```

Therefore

```text
2 * freq(m) <= # all ideals.
```

Carrier-relative complementation then turns `m` into an abundant element of
the family of upper sets.

The checked endpoint is:

```lean
posetIdeal_complement_frankl
```

## Why this matters

The WP07 proof route used a much stronger statement: average rarity for
functional-preorder ideals.  WP08-D002 shows that the **existence of one rare
element**, which is all the Frankl complement endgame needs, admits a simpler
and substantially broader proof.

So the programme now separates two layers:

```text
WP07:
functional preorder
  -> average rarity
  -> rare element
  -> Frankl abundance after complement

WP08-D002:
arbitrary finite partial order
  -> maximal-element injection
  -> rare element
  -> Frankl abundance after complement
```

WP08-D002 does not assert an average-rarity theorem for arbitrary posets.

## Remaining universal gap

Families of all order ideals of arbitrary finite posets are still a special
class of finite closure systems.  In particular they are closed under both
union and intersection.  PR #450 already proved that arbitrary union-closed
families do not have this property after reversing the exact WP07
representation claim.

The live `UC-P04` frontier therefore moves again:

> What additional closure operations, implications, or incidence structure are
> needed to pass from poset-ideal closure systems to arbitrary finite closure
> systems while retaining a rare-element argument?

This is the target of WP08-D003.
