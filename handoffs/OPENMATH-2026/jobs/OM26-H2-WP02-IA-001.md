## Assignment

Design a **complete exact search** over the fixed six-state, two-symbol blank-tape machine space. Correctness of the search quotient and pruning rules is primary. Raw search scale or a high-scoring witness is secondary.

### A. Establish the exact machine space

Define the 12 transition slots
`Q x {0,1}`, with `Q={A,B,C,D,E,F}`, and each entry in
`{0,1} x {L,R} x {A,B,C,D,E,F,H}`.

State the exact initial configuration and halting/reached-state semantics from the protected evaluator.

### B. Prove every symmetry reduction

List every transformation used to identify machines. For each transformation, prove that it preserves:

- blank-zero initial condition;
- halting versus non-halting behavior;
- exact step count;
- exact ones count where claimed;
- exact tape span;
- six-state reachability requirement.

At minimum, examine state relabeling subject to fixed start state `A` and spatial reflection `L <-> R`. Do **not** assume symbol complementation or first-write normalization is a symmetry.

If a canonical first-discovery state naming scheme is used, prove that it selects at least one representative of every valid state-renaming orbit.

### C. Give a deterministic complete enumeration

Specify an independently implementable canonical search procedure.

For a partial-transition search, define exactly:

- state carried at each node;
- next undefined transition slot selection rule;
- branch ordering;
- when a new state name may be introduced;
- when `H` may be introduced;
- how remaining undefined slots are completed;
- how canonical representatives are recognized;
- why every valid equivalence class survives.

### D. Exact pruning ledger

For every pruning rule, provide one ledger entry containing:

1. rule identifier;
2. mathematical predicate;
3. information inspected;
4. soundness proof;
5. deterministic replay/falsification test;
6. classification: `EXACT` or `HEURISTIC_ONLY`.

Heuristics may reorder exploration but must never remove a branch.

In particular, do not call configuration hashes, finite local tape windows, translation detection, Brent/Floyd cycle detection on lossy summaries, or macro-state summaries exact unless equality of the retained representation implies equality of the full future computation.

An exact repeated full configuration `(state, head, complete finite tape support)` is sufficient for periodic non-halting rejection. Any quotient weaker than that requires its own proof.

### E. Required falsification tests

Attempt to break your own design with at least these cases:

1. the protected six-step baseline;
2. the valid first-write-`0` six-step counterexample to WP01 TNF;
3. a machine that visits all six states but never halts within the validation budget;
4. a machine that halts before reaching all six states;
5. two machines related by every claimed exact symmetry, checking metric preservation;
6. one adversarial case for each nontrivial exact pruning rule.

If any test falsifies completeness or soundness, disposition must not be `EXACT_SEARCH_DESIGN_VALIDATED`.
