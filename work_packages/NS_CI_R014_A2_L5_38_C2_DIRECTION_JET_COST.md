## 2. Order-m far-low jet

For an integer `m>=1`, define

```math
R_m(t)
=
\left\lfloor
\frac{2Q(t)}{2m+1}
\right\rfloor
```

and

```math
\mathcal G_m(t)
=
\sum_{0\le q\le R_m(t)}
\|\nabla^m u_q(t)\|_\infty.
```

Bernstein gives, for a fixed Littlewood--Paley partition,

```math
\|\nabla^m u_q\|_\infty
\lesssim_m
\lambda_q^{m+3/2}
\|u_q\|_2.
```

Therefore

```math
\begin{aligned}
\mathcal G_m
&\lesssim_m
\sum_{q\le R_m}
\lambda_q^{m+3/2}
\|u_q\|_2
\\
&=
\nu^{-1/2}
\sum_{q\le R_m}
\left(
\nu^{1/2}
\lambda_q
\|u_q\|_2
\right)
\lambda_q^{m+1/2}.
\end{aligned}
```

Cauchy--Schwarz in `q` yields

```math
\mathcal G_m
\lesssim_m
\nu^{-1/2}
\mathcal D(t)^{1/2}
\left(
\sum_{q\le R_m}
\lambda_q^{2m+1}
\right)^{1/2}.
```

The geometric shell sum satisfies

```math
\left(
\sum_{q\le R_m}
\lambda_q^{2m+1}
\right)^{1/2}
\lesssim_m
\lambda_{R_m}^{m+1/2}.
```

By the definition of `R_m`,

```math
\left(m+\frac12\right)R_m
\le
Q.
```

Hence

```math
\lambda_{R_m}^{m+1/2}
\le
\Lambda.
```

Thus

```math
\boxed{
\mathcal G_m(t)
\lesssim_m
\nu^{-1/2}
\Lambda(t)
\mathcal D(t)^{1/2}.
}
```

The theorem above controls derivatives of the raw LP velocity components.

A normalized direction typically has schematic form


Already at first derivative,


Higher derivatives contain higher inverse powers of `|b|` and mixed products

Therefore raw bounds on


do not imply bounds on


without a lower bound or a compensated estimate for the normalizing amplitude.

Neither A2 nor the Leray scalar budget supplies such a trajectorywise lower
bound by itself.

This is the exact normalization gap between the raw Eulerian jet hierarchy and
the L5-37 deformation cocycle.
