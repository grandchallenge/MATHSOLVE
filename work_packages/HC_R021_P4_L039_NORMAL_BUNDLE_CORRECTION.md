## 1. Correction

`HC_R021_P4_L038_WITHDRAWAL_FULL_SUPPORT_LOCAL_EXT.md` (`L039`) correctly proves that, for the ideal `I=I_S` of a smooth codimension-two local complete intersection `S subset X`,

```text
mathcal Ext^j_X(I,I)=0,  j>=2.
```

Its global identification of the degree-one self-Ext sheaf was written with the wrong dual. The correct identification is

```text
mathcal Ext^1_X(I_S,I_S) ~= N_(S/X)
                         ~= (I_S/I_S^2)^vee.          (1.1)
```

not `I_S/I_S^2`.

## 2. Derivation

From

```text
0 -> I_S -> O_X -> O_S -> 0
```

and the codimension-two regular-immersion formula

```text
mathcal Ext^2_X(O_S,O_X) ~= det N_(S/X),
mathcal Ext^j_X(O_S,O_X)=0 for j!=2,
```

one gets the usual deformation-theoretic identification

```text
mathcal Ext^1_X(I_S,I_S) ~= Hom_S(I_S/I_S^2,O_S)
                         ~= N_(S/X).
```

Equivalently, on a local regular-sequence chart `I=(f,g)`, both conormal and normal bundles become free rank-two modules, which is why the affine calculation in `L039` detected the correct rank but did not retain the transition-function dualization.

## 3. Correct local-to-global filtration

The local-to-global self-Ext spectral sequence therefore places

```text
Ext^2_X(I_S,I_S)
```

in filtrations generated by

```text
H^2(X,O_X)
```

and

```text
H^1(S,N_(S/X)),                              (3.1)
```

subject to the spectral-sequence extension/differential data.

This is the standard embedded-deformation term. It is also the term used in the subsequent Schottky-defect analysis `L041-L043`.

## 4. Effect on L039 and later work

The following conclusions of `L039` are unchanged:

1. the generic full-support codimension-two ideal has projective dimension one;
2. its local `Ext^2_R(I,I)` vanishes;
3. `L038` remains withdrawn;
4. the generic Gauss-map/Fitting argument cannot establish a pointwise obstruction;
5. the true obstruction is global/local-to-global;
6. the derived-dual same-support lane remains live.

Only the bundle named in the global degree-one filtration is corrected.
