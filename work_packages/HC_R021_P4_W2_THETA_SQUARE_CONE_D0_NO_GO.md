## 1. Purpose

Test the most canonical non-split derived-dual construction suggested by `L039-L040` on a smooth Abel-Jacobi surface.

Let `C` be a Brill-Noether general genus-four curve,

```text
X = J(C),
S = W_2(C) subset X,
```

with principal polarization `Theta`. Put

```text
E := I_S(Theta).
```

Because `S` is contained in a suitable theta divisor, the theta section gives a canonical tensor-square class and hence a map from the derived dual of `E` to `E`. Its cone is genuinely non-split along `S` and is locally a surface modification of the standard double-theta block.

The construction is nevertheless not on a positive secant ray: its Chern character is exactly `2 Theta`. Thus it is the `d=0` endpoint rather than a solution of the `d>0` rank-20 problem.

## 2. Cohomology class and canonical class of W2

For a genus-four Jacobian the Abel-Jacobi surface has the minimal class

```text
[S] = Theta^2 / 2.                              (2.1)
```

On `C^(2)` let `x` be the divisor class obtained by adding a fixed point and let `theta` be the pullback of the principal polarization. The standard symmetric-product formulas give

```text
x^2 = 1,
x theta = 4,
theta^2 = 12,                                  (2.2)
```

and

```text
K_(C^(2)) = x + theta.                          (2.3)
```

Hence

```text
K_S . Theta|_S = 4 + 12 = 16.                  (2.4)
```

Since `H^6(X,Q)` in the relevant algebraic direction is generated by `Theta^3`, write

```text
i_* K_S = a Theta^3.
```

Intersecting with `Theta` and using

```text
int_X Theta^4 = 4! = 24
```

gives

```text
a = 16/24 = 2/3,
```

so

```text
i_* K_S = (2/3) Theta^3.                       (2.5)
```

## 3. GRR for the structure sheaf of S

Because `X` is an abelian fourfold,

```text
K_X = 0,
```

and adjunction gives

```text
det N_(S/X) = K_S.
```

For a codimension-two regular immersion,

```text
ch(i_* O_S) = i_*(td(N_(S/X))^(-1)).
```

Therefore

```text
ch_2(O_S) = [S] = Theta^2/2,                   (3.1)
ch_3(O_S) = -(1/2) i_* c_1(N_(S/X))
           = -(1/3) Theta^3.                  (3.2)
```

Terms of degree eight are irrelevant for the odd Chern character.

## 4. Odd Chern character of I_S(Theta)

From

```text
ch(I_S) = 1 - ch(O_S)
```

and

```text
ch(E) = exp(Theta) ch(I_S),
```

the degree-two odd term is

```text
ch_1(E) = Theta.                               (4.1)
```

The degree-six term is

```text
ch_3(E)
 = Theta^3/6
   - Theta (Theta^2/2)
   - ch_3(O_S)
 = Theta^3(1/6 - 1/2 + 1/3)
 = 0.                                          (4.2)
```

Consequently

```text
odd(ch(E)) = Theta.                            (4.3)
```

Since `X` has dimension four, these are all odd Chern-character degrees.

## 5. The canonical derived-dual map

Locally write the ideal of `S` as

```text
I_S = (t,g),
```

where `t=0` is the theta divisor. The theta section belongs to `I_S(Theta)`, so its tensor square defines a global section of

```text
E tensor^L E.
```

By perfect duality this gives a morphism

```text
e : E^vee -> E.                               (5.1)
```

Define

```text
C_S := Cone(e : E^vee -> E).                  (5.2)
```

Its K-class is

```text
[C_S] = [E] - [E^vee],
```

and therefore

```text
ch(C_S)
 = ch(E) - ch(E^vee)
 = 2 odd(ch(E))
 = 2 Theta.                                   (5.3)
```

Thus the canonical non-split cone is a pure odd object, but on the pure-spinor endpoint rather than a positive secant class.

## 6. Explicit local presentation

Use the regular-sequence resolution

```text
0 -> R --(-g,t)^T--> R^2 -> I_S -> 0.
```

The tensor-square class represented by the theta generator corresponds to the matrix unit selecting `t tensor t`. The cone of the resulting dual map is represented by a `3 x 3` two-term matrix. Cancelling a unit row/column gives the equivalent presentation

```text
R^2 --M--> R^2,

M = [ t    0 ]
    [ g^2 -t ].                               (6.1)
```

Hence

```text
det(M) = -t^2.                                (6.2)
```

Away from `S` inside the theta divisor, `g` is a unit and the module is equivalent to the ordinary double-theta block. Along `S`, the off-diagonal `g^2` records a genuine same-support surface modification.

This confirms that the derived-dual construction is not merely the split object of `L040`, even though its characteristic class is the same `d=0` odd endpoint.

## 7. HC-R021-L045 — d=0 cone no-go

### Statement

For the Abel-Jacobi surface `W_2(C)` of a genus-four Jacobian, the canonical theta-square morphism

```text
I_S(Theta)^vee -> I_S(Theta)
```

has a non-split cone with local matrix (6.1), but

```text
ch(C_S) = 2 Theta.
```

It therefore does not realize

```text
2 beta_d = 2 Theta - (d/3) Theta^3
```

for any positive secant parameter `d`.

The construction is useful as a local model for same-support dual coupling, but it does not itself advance the positive-secanta second-factor class.

### Proof

Sections 2-6.

QED.

## 8. Refined dual-pair frontier

A successful use of the derived-dual cone mechanism must start with an actual positive-secanta object `E_d` satisfying

```text
odd(ch(E_d)) = beta_d,
d > 0,
```

and must find a nonzero morphism

```text
E_d^vee -> E_d
```

whose cone retains the surface/point corrections responsible for the cubic term.

For the full-support secant construction of `L039-L042`, this is equivalent to a concrete global section problem in

```text
H^0(E_d tensor^L E_d).
```

The single-surface theta-square section is insufficient because it only sees the `d=0` endpoint.
