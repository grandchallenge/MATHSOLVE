# WP19 theorem — first Fitting ideal removes the rank-one quotient choice

## Setup

Let

`R := Z_2`

and let the protected WP16B module be

`X_E := Sel_{2^infinity}^{Kum}(E/Q)^vee`.

Protected WP16B proves that `X_E` is finitely generated of rank one over `R` and that

`T_E := Tor_R(X_E) = Sha(E/Q)[2^infinity]^vee`

is finite. It also proves that

`X_E/T_E`

is free of rank one.

Write `Fitt_R^i(M)` for the `i`-th Fitting ideal of a finitely presented `R`-module `M`, with `Fitt_R^0` the usual initial Fitting ideal.

## Theorem `BSD-A1-WP19-FITT1-001`

For every curve in the protected selected class,

`Fitt_R^1(X_E) = Fitt_R^0(T_E)`.

Consequently

`Fitt_{Z_2}^1(X_E) = 2^{len_{Z_2} T_E} Z_2`

and, using protected WP16A/WP16B,

`v_2(Fitt_{Z_2}^1(X_E))`

`= len_{Z_2} T_E`

`= len_{Z_2} Sha(E/Q)[2^infinity]`

`= lim_n (ord_2 #Sel_{2^n}(E/Q)-n)`.

### Proof

Because `X_E/T_E` is free rank one over `R`, the short exact sequence

`0 -> T_E -> X_E -> X_E/T_E -> 0`

splits as an exact sequence of `R`-modules: the quotient is projective because it is free. Hence, noncanonically,

`X_E ~= R direct_sum T_E`.

The splitting is used only for the algebraic calculation below. The resulting Fitting ideal is intrinsic and does not depend on a chosen splitting or basis.

Since `R=Z_2` is a discrete valuation ring, the structure theorem for finite `R`-modules gives

`T_E ~= direct_sum_{j=1}^r R/(2^{a_j})`

for integers `a_j>=1`; if `T_E=0`, take `r=0`.

Therefore `X_E` admits the square presentation

`R^{r+1} --A--> R^{r+1} -> X_E -> 0`

with diagonal presentation matrix

`A = diag(0, 2^{a_1}, ..., 2^{a_r})`.

By definition, `Fitt_R^1(X_E)` is generated by the `r x r` minors of this `(r+1) x (r+1)` presentation matrix.

Every such minor containing the zero diagonal direction vanishes. The minor obtained by deleting the first row and first column is

`2^{a_1+...+a_r}`.

Hence

`Fitt_R^1(X_E) = 2^{a_1+...+a_r} R`.

For the torsion module `T_E`, the diagonal presentation

`diag(2^{a_1},...,2^{a_r})`

shows

`Fitt_R^0(T_E) = 2^{a_1+...+a_r} R`.

Thus

`Fitt_R^1(X_E)=Fitt_R^0(T_E)`.

The same calculation includes the case `T_E=0`: then `X_E ~= R`, `Fitt_R^1(X_E)=R`, and `Fitt_R^0(0)=R`.

Finally,

`a_1+...+a_r = len_R(T_E)`.

Protected WP16B identifies this length with the WP16A stabilized Selmer integer and with the `2`-primary Sha length. This gives every displayed equality. QED.

## Corollary `BSD-A1-WP19-TARGET-001`

The selected target `BSD-R2-A1` is equivalent to

`delta_2(E) = v_2(Fitt_{Z_2}^1(X_E))`

for every curve in the protected selected class.

### Proof

Protected WP16B proves that `BSD-R2-A1` is equivalent to

`delta_2(E)=v_2(Fitt^0_{Z_2}(T_E))`.

The theorem proves

`Fitt^1_{Z_2}(X_E)=Fitt^0_{Z_2}(T_E)`.

Substitution gives the claim. QED.

## Why this representation matters

The first-Fitting formulation removes one interface from the final theorem problem.

A future theorem need not:

- choose a generator of the rank-one free quotient;
- choose a splitting `X_E -> X_E/T_E`;
- choose a possibly nonprimitive Heegner or Mordell-Weil generator and then repair its index merely to define the algebraic invariant.

It may act directly on the canonical rank-one module `X_E` and compute its intrinsic first Fitting ideal.

This is the rank-one analogue of the strong finite-level Fitting viewpoint. It does **not** prove that any existing odd-prime strong Fitting theorem extends to `p=2`.
