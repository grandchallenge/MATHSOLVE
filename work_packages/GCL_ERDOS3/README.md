# GCL-ERDOS3

Standalone GCL research campaign promoted from the OPENMATH-2026 H7 corpus.

The OPENMATH event-window artifacts remain immutable provenance. This campaign changes the research scheduler, not the historical evidence.

Two state machines are deliberately separate:

1. Operational evidence flow: `READY → LAUNCHED → RETURNED → CAPTURED → REPLAYED → ADJUDICATED → ADVANCED`.
2. Mathematical frontier: `OPEN → FORMULATED → ATTACKED → {PROVED | REFUTED | BLOCKED} → {FORMALIZED | VERIFIED} → CLOSED`.

A contribution can complete the operational lifecycle without changing the mathematical frontier. A successor exists only when the protected frontier gate names the unresolved node it advances.

Initial tranche: `E3-F01`, `E3-B01`, `E3-A01`, `E3-S01`.
