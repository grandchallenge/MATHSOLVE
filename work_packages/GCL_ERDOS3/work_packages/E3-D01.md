# E3-D01 — digit-and-carry compiler for cross-block 4-APs

Frontier node: `E3-Q4-DENSITY-LOSS`.

## Mission

Construct an exact finite-state representation of all four-term arithmetic
progressions crossing a fixed number of equal dyadic blocks.

Fix (Lge1), (m=2^L), and (N=2^n). For
(Asubseteq[0,mN)), define residue fibers

[
A_i:={uin[0,N):iN+uin A},qquad 0le i<m.
]

Represent a positive common difference uniquely as

[
d=qN+v,qquad qge0,quad 0le v<N.
]

For a starting residue (u), the term (x+t d) has carry

[
c_t=leftlfloorrac{u+t v}{N}ightfloor,qquad t=0,1,2,3.
]

## Required work

1. Derive the exact block-index/residue formula for all four terms:
   coarse index, carry, and residual coordinate.

2. Classify all feasible carry vectors
   ((c_0,c_1,c_2,c_3)) and give necessary and sufficient inequalities on
   (u,v) for each type.

3. For the smallest useful (m) (test (m=4) first, then (m=8) only if
   necessary), compile the cross-block (4)-AP-free condition into a finite
   family of forbidden relations among fibers (A_i).

4. Separate:
   - within-fiber progressions already controlled by (r_4(N));
   - same-residue cross-block progressions;
   - genuine carry-mediated progressions.

5. Identify a minimal subset of carry types whose exclusion would already
   imply a nontrivial gluing penalty. Prove that implication or return the exact
   missing inequality.

6. State the compiled object in a form suitable for both a human proof and
   E3-C01's exact finite optimization: hypergraph, constraint matrix, or an
   equivalent finite combinatorial structure.

## Adversarial requirement

Do not assume carries are negligible. A representation that silently discards
carry-mediated progressions is a failed result.

## Completion

Return one of:

- `FINITE_CARRY_REPRESENTATION_PROVED`;
- `GLUING_SUBSYSTEM_PROVED`;
- `REPRESENTATION_DEFECT`;
- `EXACT_BLOCKER`.
