# E3-S04 — source audit for cross-fiber stability and supersaturation

Frontier node: `E3-Q4-DENSITY-LOSS`.

External sources: PRIMARY_SOURCES_REQUIRED.

## Mission

Search for existing theorem interfaces that control four-term progressions
across several functions/fibers, rather than another pointwise bound for
(r_4(N)).

Prioritize exact primary-source statements concerning:

- multilinear (4)-AP counting operators;
- quantitative Varnavides or supersaturation results;
- popular-difference theorems;
- (U^3)/quadratic-uniformity counting lemmas;
- arithmetic removal/stability statements;
- multi-function or colored/fibered progression counts;
- density-increment statements whose conclusion is local enough to interact
  with the gluing-defect representation.

## Required source checks

At minimum inspect the exact relevant interfaces in:

1. Green–Tao, *New bounds for Szemerédi's theorem, III* (2017);
2. Gowers' higher-order Fourier/Szemerédi work as needed for the exact
   multilinear interface;
3. Gowers, *A uniform set with fewer than expected arithmetic progressions of
   length 4* (2020), as an explicit warning against unjustified
   Fourier-uniform random-count assumptions;
4. Green, *Arithmetic progressions at the Journal of the LMS* (2026), for the
   current (r_4) frontier and source pointers.

Add other primary sources only when they bear directly on the requested
interface.

## Required work

For every candidate theorem, record:

- exact theorem/proposition identifier;
- ambient group/interval;
- hypotheses and parameter dependence;
- whether it applies to one set or four separate functions/fibers;
- quantitative conclusion;
- whether the constants are effective enough to support a power-type gluing
  penalty;
- exact obstruction to instantiating it on the tranche's fibers.

Do not report “supersaturation exists” without the quantitative dependence
needed for this frontier.

## Promotion criterion

A source interface is useful only if you can give a rigorous mapping from its
hypotheses to a concrete gluing statement or identify one named missing bridge.
