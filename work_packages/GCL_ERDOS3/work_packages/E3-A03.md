# E3-A03 — adversarial attack on fixed-step density loss

Frontier node: `E3-Q4-DENSITY-LOSS`.

## Mission

Attempt to falsify the promoted route before the campaign invests in proving
it.

The target under attack is the existence of fixed
(Lge1), (c>0), (n_0), and (0<	heta<1) such that

[
a_{n+L}le a_n(1-c a_n^	heta)
quad(nge n_0).
]

## Required work

1. Search for a theorem-grade lower transfer construction relating
   (r_4(MN)) or (a_{n+L}) to (r_4(N)) or (a_n), using digital,
   product, separated-block, tensor, or Freiman-embedding ideas.

2. Treat carries exactly. A putative product construction is invalid if a
   cross-digit four-term progression survives.

3. Determine whether any valid construction can produce arbitrarily long
   near-plateaux, quantified as
   [
   a_n-a_{n+L}=o(a_n^{1+	heta})
   ]
   for every or some (	heta<1).

4. Audit known lower-bound constructions for (r_3) and (r_4), including
   Behrend/Rankin/O'Bryant-type constructions and later improvements where
   relevant. Distinguish carefully:
   - a pointwise lower bound on (a_n);
   - a genuine relation between (a_n) and (a_{n+L}).
   A pointwise lower bound alone does not refute a recurrence.

5. Strengthen the previously known obstruction on power recurrences
   (a_{2n}le C a_n^p) if a better primary lower construction justifies it.
   State exactly which lower bound is used.

6. If the promoted density-loss route survives, report the strongest valid
   lower-transfer inequality found and what it forces on possible
   ((L,c,	heta)).

## Completion

Return one of:

- `DENSITY_LOSS_REFUTED`;
- `PARAMETER_REGION_REDUCED`;
- `NO_COUNTEREXAMPLE_IN_DECLARED_FAMILY`;
- `EXACT_BLOCKER`.
