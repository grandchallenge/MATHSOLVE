# E3-C01 — exact finite gluing experiment and dual-certificate search

Frontier node: `E3-Q4-DENSITY-LOSS`.

## Mission

Use exact finite optimization only as a representation-discovery instrument.
The goal is not to extrapolate a theorem from small (N), but to discover
small-support inequalities or forbidden patterns that can be handed back to a
proof lane.

## Required model

For (min{4,8}) and feasible (N), model a subset
(Asubseteq[0,mN)) with one binary variable per integer and one exclusion
constraint per nontrivial four-term arithmetic progression.

Record the block fibers (A_isubseteq[0,N)).

## Required work

1. Reproduce exact values of (r_4(N)) on an independently checkable small
   range before using the solver for new measurements.

2. Compute the exact gluing gap
   [
   G_m(N):=m,r_4(N)-r_4(mN)
   ]
   where feasible, and preserve a witness/certificate for every optimum.

3. For global extremizers at scale (mN), record the vector of fiber deficits
   [
   r_4(N)-|A_i|.
   ]

4. Solve conditioned variants in which each fiber is forced to be within a
   prescribed deficit of (r_4(N)). Determine the smallest deficit at which
   global feasibility appears.

5. Build the digit/carry hypergraph explicitly and solve useful LP relaxations.
   Search the LP dual for sparse or symmetric certificates whose inequalities
   can be stated without a solver.

6. Test candidate exponents only as diagnostics, for example ratios based on
   [
   D_{L,n}/a_n^{1+	heta}.
   ]
   Do not promote an exponent from finite data.

## Reproducibility

Return exact code or pseudocode sufficient for independent replay, exact
instances, solver/version identity if a solver is used, and machine-checkable
witnesses where practical.

## Completion

Return one of:

- `EXACT_CERTIFICATE_CANDIDATE`;
- `FINITE_PATTERN_DISCOVERED`;
- `COUNTEREXAMPLE_TO_LOCAL_HEURISTIC`;
- `COMPUTATIONAL_NO_SIGNAL`.

No computational disposition by itself proves a frontier theorem.
