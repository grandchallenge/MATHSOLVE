# WP60K source note — finite BSS Hypothesis 3.2 dependency

This note records only the source/proof dependency already admitted through protected MATHFORGE WP60F/WP60G and checked against the BSS II primary-source surface during theorem construction.

The relevant finite coefficient condition is BSS II Hypothesis 3.2(iii):

`H^1(K(A)_M/K,A)=0`

and

`H^1(K(A)_M/K,A^*(1))=0`.

Protected MATHFORGE WP60F records that BSS II Theorem 5.20 and Theorem 5.2 assume Hypothesis 3.2 and that the integral inverse-limit control is built from the finite coefficient theory. Protected MATHFORGE WP60G records the exact restriction/cohomology role of 3.2(iii) in Lemma 3.9.

WP60K does not import a new external theorem. It proves internally that the formal literal-`p=2` specialization of the existing finite hypothesis fails for `A=E[4]` on the selected lane.

The BSS papers themselves are written under odd-prime standing conventions in the relevant sections. Accordingly this package makes an applicability/proof-mechanism statement only: the unchanged finite hypothesis, if formally specialized to literal `p=2`, is false at mod `4`. It does not attribute a published `p=2` theorem to BSS.
