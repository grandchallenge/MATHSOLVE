# Next analytic target

## `BSD-R2-A1-2ND-MAIN-RECIPROCITY`

The next target is not another descent or normalization audit. It is the missing deep theorem itself.

Construct or locate an exact theorem valid for the selected good-ordinary-at-2, globally irreducible `E[2]`, rank-one class that supplies the analytic-to-arithmetic 2-primary length equality specified in `03_RECIPROCITY_OBLIGATION.md`.

Two routes remain admissible.

### Route A — direct over Q

Develop an integral ordinary `p=2` main-conjecture/Euler-system and rank-one reciprocity theorem that works despite standard residual non-distinguishedness and carries the exact WP07 local multiplier and all WP00 normalizations.

### Route B — Heegner/Kolyvagin over an auxiliary quadratic field

Develop an integral `p=2` primitivity or main-conjecture theorem over a suitable imaginary quadratic field, combine it with exact rank-one reciprocity and the WP06 descent identity, and supply an exact rank-zero twist input.

### Required output

The route must end with an equality of ordinary integers/2-adic lengths that can be compared directly with

`ord_2(L'(E,1)/(Omega_E Reg_E))`,

not an equality after inverting `2` and not a formula only up to powers of `2`.

### Stop rule

If no existing source meets these requirements, the boundary is a genuine new integral `p=2` reciprocity/Iwasawa theorem problem. Do not disguise that boundary as missing documentation or source migration.
