# WP60J source note — exact BSS II hypothesis surface

This note records the exact primary-source clauses checked before exact-head review.

For Burns–Sakamoto–Sano II, Hypothesis 3.2 has exactly three clauses:

1. residual irreducibility;
2. existence of `tau in G_{K_M}` with `A/(tau-1)A ~= R`;
3. vanishing of `H^1(K(A)_M/K,A)` and `H^1(K(A)_M/K,A^*(1))`.

Hypothesis 3.3 asks for vanishing of residual primal and dual global invariants.

An earlier WP60J draft mistakenly mentioned a nonexistent Hypothesis 3.2(iv); that sentence was removed before review. This note is documentary only and does not create a new theorem premise beyond the protected BSS source interfaces already admitted through MATHFORGE.
