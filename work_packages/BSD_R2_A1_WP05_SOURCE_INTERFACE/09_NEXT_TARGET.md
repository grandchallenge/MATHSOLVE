# Next analytic target

## `BSD-R2-A1-2DESCENT-CONTROL`

The next theorem-development target is an exact **integral 2-primary control lemma** that removes one concrete defect in the odd-prime rank-one route.

For an auxiliary imaginary quadratic extension `K/Q` chosen only after its Heegner and local hypotheses are stated, construct the restriction/corestriction comparison between the ordinary `2^infinity` Selmer structures for `E/Q`, its quadratic twist, and `E/K`. Prove an exact sequence, or an equivalent finite-length identity, in which every kernel and cokernel is explicitly defined and its `Z_2`-length is retained.

Acceptance requires:

1. the local condition at `2` to be defined from the actual good-ordinary 2-divisible-group structure, not imported from an odd-prime slogan;
2. all bad-prime local conditions and Tamagawa contributions to be explicit;
3. no use of `(1 +/- tau)/2` as an integral projector over `Z_2`;
4. exact accounting for finite restriction/corestriction kernels and cokernels;
5. an explicit statement of which remaining 2-adic main-conjecture and reciprocity inputs would still be needed after the control lemma.

A direct-over-`Q` integral 2-adic control theorem is an admissible alternative and would bypass this auxiliary quadratic target. The campaign does not assert that quadratic base change is logically necessary.

Success on this next target would not prove `BSD-R2-A1`; it would remove a named integral obstruction and sharpen the remaining Iwasawa/reciprocity debt.
