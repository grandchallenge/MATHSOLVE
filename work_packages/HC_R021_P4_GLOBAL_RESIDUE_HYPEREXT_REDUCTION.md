## 1. Purpose

Continue `HC-R021-L049` from the exact global question

```text
Ext_X^1(B_D,C_corr) -> Ext_R^1(B,C)
```

at a generic point of a correction curve

```text
C = D cap H cap A.
```

The local calculation in `L049b` shows that two independent co-supported channels kill the full pure-bivector characteristic class. The present package determines where such global channels can and cannot come from.

The main conclusions are:

1. the ordinary global chain-map channel through the corrected ideal `E=I_C(D)` is exactly one-dimensional;
2. that one-dimensional channel is generated by the theta square and cannot supply the two independent local residue coordinates of `L049`;
3. any successful rank-two globalization must therefore come from the genuinely derived part involving `E^vee`;
4. the line-bundle classes carrying that derived contribution are all nondegenerate of index `2`, with explicit cohomology dimensions;
5. the ambient `H^0=0` observation in `L049` is therefore not a no-go: the remaining problem is a finite-dimensional `H^2` cup-product/hypercohomology calculation.

No rank-two globalization is claimed here.

## 2. Setup

Let `X` be the abelian fourfold of the active RM package. Let

```text
C = D cap H cap A
```

be a smooth complete-intersection correction curve and let `t` denote the theta section cutting out `D`.

Set

```text
E := I_C(D),
B := B_D := O_(2D)(D).
```

The ordinary double-theta block has the standard two-term resolution

```text
B = [ O(-D) --t^2--> O(D) ]
```

in degrees `-1,0`.

The corrected cone of `L049` is

```text
C_corr = Cone(E^vee -> E),
```

where the map is induced by the square of the theta section.

## 3. Exact computation of `RHom(B,E)`

Because `B` is represented by the two-term locally free complex above,

```text
RHom(B,E)
  = [ Hom(O(D),E) -> Hom(O(-D),E) ]
  = [ I_C -> I_C(2D) ],
```

with differential multiplication by `t^2`.

Since `I_C` is torsion-free and `t` is nonzero,

```text
I_C --t^2--> I_C(2D)
```

is injective. Hence `RHom(B,E)` has a single cohomology sheaf, in internal degree one:

```text
Q := I_C(2D) / t^2 I_C.
```

Therefore

```text
Ext_X^r(B,E) = H^(r-1)(X,Q).                         (3.1)
```

In particular

```text
Ext_X^1(B,E) = H^0(X,Q).                             (3.2)
```

## 4. The ordinary global channel is one-dimensional

From

```text
0 -> I_C --t^2--> I_C(2D) -> Q -> 0                 (4.1)
```

we first note

```text
H^0(I_C)=0,
H^1(I_C)=0.                                           (4.2)
```

The first equality follows because a global function vanishing on nonempty `C` is zero. The second follows from the standard weak-Lefschetz injection

```text
H^1(O_X) -> H^1(O_C)
```

for a smooth complete intersection of ample divisors, together with the exact sequence

```text
0 -> I_C -> O_X -> O_C -> 0.
```

Thus

```text
H^0(Q) ~= H^0(I_C(2D)).                              (4.3)
```

Use the Koszul resolution of `I_C(2D)`:

```text
0 -> O(D-H-A)
  -> O(D-H) direct_sum O(D-A) direct_sum O(2D-H-A)
  -> O(D) direct_sum O(2D-H) direct_sum O(2D-A)
  -> I_C(2D) -> 0.                                   (4.4)
```

In the RM chamber of `L049`, every nonzero line bundle in (4.4) other than `O(D)` has one positive and one negative RM block and therefore index `2`. Hence each has

```text
H^0 = H^1 = 0.                                       (4.5)
```

The principal polarization `D` has

```text
h^0(O(D))=1.
```

Consequently the degree-zero edge of (4.4) gives

```text
H^0(I_C(2D)) = C * t^2.                              (4.6)
```

Combining (3.2)-(4.6),

```text
Ext_X^1(B,E) ~= C.                                   (4.7)
```

The unique ordinary channel is the theta-square channel. It cannot supply the two independent local residue coordinates required by `L049b`.

### HC-R021-L050a

The rank-two co-supported repair cannot globalize through ordinary global chain maps `B -> E[1]` alone.

## 5. The remaining channel is genuinely derived

Apply `RHom(B,-)` to

```text
E^vee -> E -> C_corr -> E^vee[1].                   (5.1)
```

The relevant exact segment is

```text
Ext^1(B,E)
 -> Ext^1(B,C_corr)
 -> Ext^2(B,E^vee)
 -> Ext^2(B,E).                                      (5.2)
```

The first term is one-dimensional by `L050a`. Therefore any second independent residue class must have nonzero image in

```text
Ext^2(B,E^vee).                                      (5.3)
```

The double-theta block is self-dual up to the hypersurface shift:

```text
RHom(B,O_X) ~= B[-1].                                (5.4)
```

Since `K_X` is trivial and `dim X=4`, Serre duality and (3.1) give

```text
Ext^2(B,E^vee)
 ~= Ext^1(E,B)
 ~= Ext^3(B,E)^*
 ~= H^2(X,Q)^*.                                      (5.5)
```

Thus the unresolved global residue channel is an explicitly finite-dimensional derived cohomology problem on `Q`.

## 6. Exact RM indices and dimensions

Retain the `L049` RM normal form

```text
D=(1,1),
H=(a,b),
A=(a^2,b^2),
ab=1,
a+b=tau,
0<a<1<b,
tau>=3.
```

The two local residue coordinates of `L049` globalize with numerical classes

```text
L_H := 2D-H,
L_A := 2D-A,
```

and the terminal correction component has class

```text
M := H+A-D.
```

Their RM weight products are

```text
(2-a)(2-b) = 5-2 tau,
(2-a^2)(2-b^2) = 9-2 tau^2,
(a+a^2-1)(b+b^2-1) = 5-tau^2.                       (6.1)
```

For `tau>=3` all three products are negative, while the first RM weight is positive and the second negative. Hence all three line bundles have index `2`.

For a line bundle with RM weights `(x,y)` on this principally polarized fourfold,

```text
chi = (xy)^2.
```

Mumford's index theorem therefore gives

```text
h^2(L_H) = (2 tau-5)^2,
h^2(L_A) = (2 tau^2-9)^2,
h^2(M)   = (tau^2-5)^2,                              (6.2)
```

and all other ambient cohomology groups vanish.

This proves that the absence of ambient sections in `L049` is not an extinction result. The only possible ambient contribution is precisely in the Cech degree needed for the derived hyper-Ext channel.

## 7. Restriction degrees on the correction curve

Normalize the two RM block classes `U,V` by

```text
D=U+V,
D^4=24.
```

Since the coefficient of `U^2 V^2` in `D^4` is `6`,

```text
integral_X U^2 V^2 = 4.                              (7.1)
```

A direct symmetric-polynomial calculation then gives

```text
deg_C(L_H)
 = (2D-H) D H A
 = 8 (tau-1)^2 (tau+1),                              (7.2)

 deg_C(L_A)
 = (2D-A) D H A
 = 4 tau (tau^2-1).                                  (7.3)
```

Adjunction gives

```text
K_C=(D+H+A)|_C,
2g(C)-2 = 8 (tau-1)(tau+1)^2.                        (7.4)
```

Hence

```text
chi(C,L_H|_C)
 = deg(L_H)+1-g
 = 4 (tau^2-1)(tau-3) >= 0,                          (7.5)

chi(C,L_A|_C)
 = deg(L_A)+1-g
 = -4 (tau^2-1) < 0.                                 (7.6)
```

The two residue channels are therefore globally asymmetric. The `2D-H` coordinate is numerically at or above the Riemann-Roch threshold (`tau=3` is the boundary case), whereas `2D-A` lies below it. This does not by itself decide either `H^0(C,L_i)` because the restrictions are special, not generic line bundles on `C`.

## 8. HC-R021-L050 — exact remaining calculation

The globalization problem is no longer an unrestricted Ext computation.

It reduces to the `H^2` hypercohomology/cup-product differential controlling the map

```text
H^2(X,Q)^* -> H^1(X,Q)                               (8.1)
```

appearing in (5.2), followed by the generic-residue edge map to the two local coordinates of `L049`.

Equivalently, after expanding `Q` with the Koszul resolution, one must compute a finite-dimensional matrix assembled from cup products by the three defining theta sections of `D,H,A` between index-two line-bundle cohomology groups. The only numerical classes that can carry the two required residues are `2D-H` and `2D-A`, with the terminal compatibility carried by `H+A-D`.

A rank-two image at the generic point of `C` permits the co-supported repair to proceed. Rank less than two closes this escape.

The ambient index theorem alone does not decide the rank.
