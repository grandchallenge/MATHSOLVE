## 2. Exact finite auxiliary field

For `K=Q`, `R=Z/4`, the BSS integer is `M=4`. Since `Q` has class number one and units `{+-1}`,

`K_4=Q(mu_8)`.

Put

`L:=Q(E[4])`.

The Weil pairing gives `Q(mu_4) subset L`.

### Lemma `BSD-A1-WP60L-AUX-FIELD-001`

`L intersect Q(mu_8)=Q(mu_4)`.

### Proof

Protected WP60J gives full 2-adic image. Hence there is `sigma in G_Q` with

`rho_{E,2-adic}(sigma)=diag(5,1)`.

Modulo `4` this matrix is the identity, so `sigma` fixes `L=Q(E[4])`. Its determinant is `5 mod 8`. By the Weil pairing, the determinant is the 2-adic cyclotomic character, so `sigma` acts nontrivially on `mu_8`.

Therefore `Q(mu_8)` is not contained in `L`. Since `Q(mu_8)/Q(mu_4)` is quadratic and `Q(mu_4) subset L`, the intersection is exactly `Q(mu_4)`. QED.

Consequently the BSS finite auxiliary field

`F_4:=K(A)_4=L Q(mu_8)`

satisfies

`[F_4:L]=2`.

Let

`G_4:=Gal(L/Q)=GL_2(Z/4)`,

`Gamma_4:=Gal(F_4/Q)`,

and `N:=Gal(F_4/L)`.

Then `N~=C2`, it is normal and therefore central in `Gamma_4`, and it acts trivially on `A`.

## 3. The full auxiliary cohomology group has exactly one nonzero class

### Theorem `BSD-A1-WP60L-AUX-H1-002`

Inflation is an isomorphism

`H^1(G_4,A) -> H^1(Gamma_4,A)`.

Hence

`#H^1(K(E[4])_4/Q,E[4])=2`.

### Proof

Inflation-restriction gives

`0 -> H^1(G_4,A) -> H^1(Gamma_4,A) -> H^1(N,A)^{G_4}`.

Since `N=C2` acts trivially,

`H^1(N,A)=Hom(C2,A)=A[2]`.

Because `N` is central, the induced `G_4`-action on this group is the natural action on `A[2]=E[2]`. Protected residual irreducibility gives

`E[2]^{G_4}=0`.

Thus the right-hand term vanishes and inflation is an isomorphism. WP60K gives `#H^1(G_4,A)=2`. QED.

Let `z_4` denote the unique nonzero class in this group.

## 5. Canonical local condition at the odd-depth prime

Protected WP13 gives `c_ell` odd because `n_ell` is odd. Protected WP39 therefore gives

`H^1(Q_ell,T)=H^1_ur(Q_ell,T)`.

BSS define the canonical local condition on `T` at `ell != 2` by

`H^1_Fcan(Q_ell,T)
 = ker(H^1(Q_ell,T) -> H^1(Q_ell^ur,T tensor Q_2))`.

Every unramified class is in this kernel. Since all of `H^1(Q_ell,T)` is unramified, we obtain

`H^1_Fcan(Q_ell,T)=H^1(Q_ell,T)=H^1_ur(Q_ell,T)`.

The canonical condition on the quotient `A=T/4T` is propagated from `T`, so

`H^1_Fcan(Q_ell,A)
 = im(H^1(Q_ell,T) -> H^1(Q_ell,A))`.

The local Kummer exact sequences identify `H^1(Q_ell,T)` with the 2-adic completion of `E(Q_ell)` at `ell !=2`; consequently this image is exactly the finite Kummer image

`E(Q_ell)/4E(Q_ell) -> H^1(Q_ell,E[4])`.

By Tate local duality together with the principal polarization and Weil pairing, this Kummer image is its own annihilator in `H^1(Q_ell,E[4])`.

Hence, under the Weil self-duality `A~=A^*(1)`,

`H^1_Fcan*(Q_ell,A^*(1))
 =H^1_Fcan(Q_ell,A)`.

Moreover every class in this common local condition has trivial inertia restriction because it is propagated from `H^1_ur(Q_ell,T)`.

### Theorem `BSD-A1-WP60L-LOCAL-EXCLUSION-004`

The unique nonzero auxiliary restriction-kernel class `z_4` lies in neither the primal nor the dual canonical local condition at `ell`.

### Proof

By Lemma `RAMIFIED-003`, its inertia restriction is nonzero. Every primal canonical class has zero inertia restriction by the preceding paragraph. The dual canonical condition is the same Kummer submodule under Weil self-duality, so the same exclusion holds on the dual side. QED.
