# WP38A — Native polynomial canonical witness construction, conditional on SAT decision

Pinned original upstream `vidick/MIPRE-formalization@5926bdff5db621f44682a101007ef2fe3ae8d970`, Lean 4.35.0-rc3. Protected WP37 #1293. The result formalizes standard SAT self-reducibility with actual original Cost.PolyTimeFun code, not an assertion of new general complexity-theoretic novelty.

Let D be any total original source polynomial program correct on every encoded Fml, and let xs be an arbitrary finite list of variable identifiers. At each step query D on the current formula conjoined with the positive literal for the next identifier. Retain the positive literal if YES, the negative literal otherwise. If the current formula is satisfiable then the updated one is satisfiable. For any satisfying model of the final formula, all recorded decisions agree with its restrictions to xs. The actual source code uses original formula builders, composition, and foldlAdd; the state consists of the progressively constrained formula and reverse bit list. One step increases encoded state size by at most esize i+27. Thus the native loop has an explicit polynomial certificate even for arbitrary binary identifiers and arbitrary input lists. The final reversal is native. No decision algorithm is constructed unconditionally.

The greedy output is lexicographically greatest among all restrictions of satisfying models to xs, true preferred to false. The exact semantic ordering is Preferred; antisymmetry establishes uniqueness for any canonical witness. This is stronger than arbitrary witness generation but is a standard consequence of self-reducibility. Empty and duplicate variable lists are allowed.

A separate original source polynomial parser reconstructs Fml from its actual RPN list. It handles malformed lists by a total default/top operation, and is exact on every valid source RPN. Accumulator growth is additive under each original parse step. This closes the typed formula reconstruction needed for a converse from a native witness generator back to raw-data decision, when composed with the existing WP28B2 raw node reader.

WP38A does not prove a superpolynomial bound. The unrestricted semantic target is now to exclude every polynomial witness constructor on satisfiable instances, not just particular proof widths or a greedy algorithm. The WP35 dense support and verifier plus WP34 exact valid-promise equivalence permit a further exact converse; the dependent bridge is a separate work package. No standard model concordance, P≠NP conclusion, or independent certification claimed.

Internal proof audit: greedy branch invariant uses D only on valid encoded formulas; no SAT labels are hardcoded. Polynomial growth is charged in the source model, not just number of queries. Lexicographic comparison is on restrictions of global satisfying assignments, not on all Boolean lists irrespective of feasibility. Parser correctness is only asserted on valid RPN. Fresh replay of the three new modules against pinned upstream libraries, without previous generated PNP modules, is available via WP38_REPLAY.py.
